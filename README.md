## 🎯 Proje Vizyonu ve Felsefesi

Modern web dünyasında çoğu portföy sitesi hazır şablonlar, yüksek bağımlılık boyutları ve birbirinin benzeri tasarımlardan ibarettir. **Sanctum Codex / Atlas Protocol** vizyonu ise şu 4 temel sütun üzerine kurulmuştur:

1. **Sıfır Ağır Bağımlılık (Zero Heavy Framework Overhead):**
   - Üretim ortamında sıfır React/Vue build süresi gerektiren, doğrudan tarayıcı GPU'su üzerinde çalışan saf **Vanilla ES6+ JavaScript**, **WebGL** ve **CSS3 Native Custom Properties** mimarisi.
2. **Awwwards Derecesinde Görsel & İşitsel Deneyim:**
   - Donanım hızlandırmalı 3B parçacık motoru, akıllı imleç halesi (Cursor Glow), 60 FPS yumuşak kaydırma (Scroll Scrubber) ve tarayıcının yerel **Web Audio API**'si ile üretilen ambiyans ses efektleri.
3. **Kurumsal Yazılım Mühendisliği Standartları:**
   - SOLID prensipleri, Clean Architecture, katmanlı mimari yapıları, SEO/GEO meta stratejileri, Schema.org JSON-LD semantik veri formatı.
4. **Çok Dilli ve Erişilebilir Altyapı:**
   - 50'den fazla dünya dilini destekleyen i18n dil motoru ve `Ctrl + K` klavye kısayolu ile çalışan Komut Paleti (Command Palette).

## ✨ Öne Çıkan Özellikler ve İnteraktif Modüller

### 🌌 1. Three.js 3D WebGL Hero Canvas (`three-hero.js`)
- **İnteraktif Holokron Relic:** GPU üzerinde çalışan Three.js `IcosahedronGeometry` ve `TorusGeometry` katmanları ile oluşturulmuş 3B antik nesne.
- **Dinamik Işıklandırma:** Fare hareketine duyarlı olarak nesne etrafında dönen Altın (`#e5b869`), Akkor (`#d96b27`) ve Siyan (`#3eb4a1`) nokta ışıkları (Point Lights).
- **Uzaysal Parçacık Sistemi (Particle Field):** 600+ bağımsız hareket eden ve kamera odağında süzülen 3B yıldız/toz parçacıkları.

### ⚡ 2. Akıllı İmleç Halesi (Fast & Smooth Cursor Glow)
- Yüksek performanslı **Lerp (Linear Interpolation)** algoritması ile fare hareketini milisaniyelik, yumuşak bir gecikmeyle takip eden özel halo ışık süzmesi.
- `mix-blend-mode: screen` ve `radial-gradient` kombinasyonuyla gözü yormayan premium karanlık mod efekti.

### 📜 3. Ultra-Smooth Scroll Scrubber & Bölüm Geçişleri
- Sayfa aşağı ve yukarı kaydırıldığında bölümlerin **sıfır eğrilme ve zero-skew** ile dikey eksende (`translateY`) kusursuzca belirmesini sağlayan 60 FPS donanım hızlandırmalı geçiş sistemi.
- Parallax hero kaybolma efekti ve zaman çizelgesi (Timeline) düğüm parlamaları.

### 🎮 4. Kutsal Oyun Alanı (Sanctum Mini-Games - `mini-games.js`)
Sitede ziyaretçilerin vakit geçirebileceği ve etkileşime girebileceği sıfır harici görsel varlıklı (Zero Asset) iki mini oyun:
- **Kalıntı Hizalama (3D Relic Aligner):** Fareyi basılı tutup sürükleyerek Three.js ile işlenen 3B halkaları döndürme ve antik runeleri hizalama bulmacası.
- **Şifre Terminali (Cipher Matrix Speed Test):** Yazılım geliştiriciler için dakikadaki kelime sayısını (WPM), harf doğruluğunu (Accuracy %) ve süreyi anlık hesaplayan retro siber daktilo oyunu.

### 🎵 5. Web Audio API Ambiyans Ses Sentezleyicisi (`audio-engine.js`)
- Harici hiçbir `.mp3` veya `.wav` ses dosyası yüklemeden, tarayıcının yerel **AudioContext** ve **OscillatorNode** modüllerini kullanarak kod ile sentezlenen ses efektleri.
- Tıklama sesleri, modal açılış çanları ve form gönderim sinyal bip sesleri.

### ⌨️ 6. Komut Paleti (Command Palette - `Ctrl + K`)
- IDE ve macOS Spotlight deneyimini web sitesine taşıyan komut paleti.
- Klavyeden `Ctrl + K` tuşlarına basarak sayfa bölümlerine hızlı atlama, dil değiştirme, sesi açıp kapatma veya doğrudan e-posta adresini panoya kopyalama imkânı.

## 💻 Yerel Kurulum ve Çalıştırma

Bu projeyi kendi bilgisayarınızda yerel olarak çalıştırmak ve incelemek için aşağıdaki adımları takip edebilirsiniz:

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/mericulasK/Mericulaskiray-Personal-Website.git
cd Mericulaskiray-Personal-Website
```

### 2. Geliştirme Sunucusunu Başlatın
Herhangi bir ağır paket kurulumu gerektirmeden projeyi canlı olarak sunmak için:

```bash
npm run dev
```
veya doğrudan Node.js ile:
```bash
npx serve -p 3000 .
```

### 3. Tarayıcıda Açın
Tarayıcınızın adres çubuğuna şu adresi girin:
```text
http://localhost:3000
```

## 🌐 Canlı Yayın ve CI/CD Otomasyonu

Proje, **Netlify** üzerinde barındırılmakta olup GitHub deposu ile **Continuous Deployment (Sürekli Dağıtım)** boru hattına bağlıdır.

- `main` dalına yapılan her `git push` işlemi Netlify tarafından otomatik olarak algılanır.
- `netlify.toml` dosyasında yer alan özel `Cache-Control` başlıkları sayesinde HTML dosyaları önbellek şişkinliği yapmadan ziyaretçilere anında sunulur.
